# Icône de Storyboarder BD

| Fichier | Usage |
|---|---|
| `storyboarder-bd.ico` | Windows : exécutable, installeur, raccourcis, fenêtre (16 à 256 px). |
| `storyboarder-bd-<taille>.png` | README, site, réseaux (16 à 1024 px ; 180 px pour `apple-touch-icon`). |
| `storyboarder-bd-icon.svg` | Source vectorielle (48 px et plus). |
| `storyboarder-bd-icon-32.svg` | Version simplifiée, 20 à 32 px. |
| `storyboarder-bd-icon-16.svg` | Version 16 px, au pixel près. |

Couleurs : accent `#FF7A45`, fond `#161616`, papier `#F5F5F5`, case sombre `#3A3A3A`.
